**🌍 Real-Time Air Quality Monitoring Using IoT**

**Project Overview:** The **Real-Time Air Quality Monitoring System Using IoT** is an IoT-based project designed to monitor air quality and environmental parameters in real time.
- The system uses sensors connected to an **Arduino UNO** to collect air-quality data, while an **ESP8266 Wi-Fi module** enables wireless data transmission. The readings can be displayed using an **LCD** and monitored remotely through the **Blynk IoT platform**.
  
**🎯 Aim:**
- Monitor air quality in real time using IoT.
- Measure environmental parameters such as temperature, humidity, and pressure.
- Monitor different air-quality parameters using gas sensors.
- Transmit sensor data wirelessly using ESP8266.
- Provide real-time monitoring through LCD and IoT platforms.

**🛠️ Hardware Requirements:**
- Arduino UNO
- MQ-7 Gas Sensor
- MQ-135 Gas Sensor
- DHT11 Sensor
- BMP280 Sensor
- ESP8266 Wi-Fi Module
- 16×2 LCD Display
- Breadboard
- Jumper Wires

**💻 Software Requirements:**
- Arduino IDE

**⚙️ Working:**

1. **Data Collection:** Sensors collect air-quality and environmental data.
2. **Processing:** Arduino UNO receives and processes the sensor readings.
3. **Wireless Communication:** ESP8266 transmits the data through Wi-Fi.
4. **IoT Monitoring:** Data can be monitored remotely using Blynk.
5. **Display:** Important readings can also be displayed on the LCD.

**System Flow:**

(Sensors)
    ↓
(Arduino UNO)
    ↓
(ESP8266 Wi-Fi)
    ↓
(LCD display)
    ↓
(User Monitoring)

**📊 Parameters Monitored:**

- Air Quality / Gas Levels
- Other gas parameters depending on sensor configuration
